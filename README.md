# OpenAPI Bundle Schema

Esta extensión tiene como finalidad unir contratos OpenAPI con los schemas.

## 🚀 Uso

1. Abre tu archivo OpenAPI (`.yaml` o `.yml`).
2. Abre la paleta de comandos (`Ctrl + Shift + P`).
3. Ejecuta **OpenAPI: Bundlear contrato con schemas**.
4. El resultado se mostrará en la consola "OpenAPI Bundler".
5. Se generará un archivo `*-bundled.yaml` en la carpeta /dist.

## ⚙️ Requisitos

- Tener instalado **Node.js**.
- Tener un contrato con extensión `.yaml`.

## 🧩 Funcionalidad adicional
- Botón visible en el panel del editor para archivos YAML.
- Mensajes visuales de éxito o error.
- Salida detallada en el panel “OpenAPI Bundler”.
